## دربارهٔ فری‌باف

**فری‌باف (Freebuff)** یک دستیار برنامه‌نویسی هوش مصنوعی **۱۰۰٪ رایگان** است که به‌جای اشتراک،
از طریق تبلیغات تأمین می‌شود. در چند شکل ارائه شده — **CLI**، **Desktop**، **Web**، **Cloud** و
**Chat** — و به تو اجازه می‌دهد از مدل‌های قدرتمند برنامه‌نویسی بدون هزینه استفاده کنی. روی
همان سیستم/سرور خودت اجرا می‌شود و روی فایل‌ها و دستورهای واقعی کار می‌کند.

- 🌐 سایت: **https://freebuff.com**
- 💻 نصب CLI: `npm i -g freebuff` و بعد اجرای `freebuff`
- 🧩 رایگان برای همه: بدون کلید API و بدون کارت بانکی
- 📉 محدود به بودجهٔ روزانهٔ **باک (Freebucks)** — پایین‌تر توضیح داده شده

«نگهبان فری‌باف» یک رابط تلگرامی مستقل برای فری‌باف است و **وابسته به تیم فری‌باف نیست**.
همچنان برای استفاده به حساب فری‌باف و CLI روی همان سرور نیاز داری.

## نگهبان فری‌باف چیست؟

یک ربات تلگرامی که به تو اجازه می‌دهد **فری‌باف را کامل مدیریت کنی و بدون SSH با آن چت کنی**.
یک‌بار نصبش می‌کنی و بعد از آن همه‌چیز داخل تلگرام انجام می‌شود: چت با مدل، عوض‌کردن مدل، کنترل
سرور، مدیریت چند اکانت فری‌باف، دیدن سهمیه، و اجرای دستور روی سیستم توسط مدل.

برای کسانی ساخته شده که فری‌باف را روی یک VPS دور اجرا می‌کنند و می‌خواهند از هر جا و با موبایل
کنترل راحت روی آن (و روی سرور) داشته باشند.

## ✨ قابلیت‌ها

- 💬 **چت با مدل‌های رایگان** از تلگرام، با چند جلسهٔ گفتگوی مستقل و تاریخچهٔ جدا برای هر جلسه.
- 🤖 **مدیریت مدل**: سوییچ واقعی — ربات جلسهٔ رایگان فعلی را می‌بندد و با مدل جدید دوباره
  `admission` می‌زند (سرور جلسهٔ رایگان را به یک مدل قفل می‌کند). جلوی هر مدل **مصرف
  (باک/ساعت)** و **سهمیهٔ ساعتی امروز** نوشته می‌شود؛ مدل‌های در دسترس‌نبودن **خاکستری و
  غیرقابل‌کلیک** نشان داده می‌شوند.
- 🎛 **نوع پاسخ**: 🧩 پیش‌فرض · ⚡ سریع (Lite) · 🛠 ساخت کامل (MAX/Build) · 🗺 برنامه‌ریزی (Plan) —
  همان حالت‌های CLI.
- ⚙️ **منوی تنظیمات**: نوع پاسخ، تبلیغات (روشن/خاموش)، مدل فعال، آستانهٔ هشدار انقضا و
  **تمدید خودکار جلسه** (۵ دقیقه قبل هشدار می‌دهد و سر موعد جلسه را خودکار تازه می‌کند؛ با دکمهٔ لغو).
- 👤 **چند اکانت فری‌باف** (استفادهٔ شریکی): افزودن با **ورود وب** (مکانیزم رسمی login، بدون
  نیاز به سرور برای آن اکانت و همراه دکمهٔ کپی آدرس لاگین). هنگام تمام‌شدن سهمیه با دکمه
  می‌پرسد و در صورت بی‌جوابی تا **۱ دقیقه خودکار به اکانت بعدی سوییچ می‌کند (failover)**،
  بدون قطع‌شدن جلسه.
- 💾 **بکاپ/ریستور اکانت‌ها**: بکاپ روزانهٔ خودکار + دکمه‌های بکاپ و ریستور از فایل در بخش اکانت‌ها.
- ⏳ **تایمر جلسه**: جلسهٔ رایگان دقیقاً **۱ ساعت** (سمت سرور) عمر می‌کند؛ ربات شمارش زنده (مثلاً
  «۵۱ دقیقه مانده»)، هشدار قبل از انقضا و دکمهٔ **تمدید** را فقط نزدیک انقضا نشان می‌دهد.
- 💵 **نمایش سهمیه**: مقدار **باک** مانده/استفاده‌شده و سقف تعداد جلسه، هم در «وضعیت» و هم در
  «اکانت‌ها». هنگام اتمام سهمیه پیام شفاف + دکمه‌های **افزودن اکانت / تغییر اکانت / خرید اشتراک**.
- ⌨️ **کنترل سرور (ابزارهای مدل)**: مدل می‌تواند `run_terminal_command`، `read_file`،
  `list_directory` و `write_file` را روی همین سرور اجرا کند (حلقهٔ چندگامی). دستورهای خطرناک
  تأیید **اجرا/لغو** می‌گیرند.
- 🎛 **دو رابط هم‌زمان**: دکمه‌های شیشه‌ای برای همه‌چیز + **کیبورد ثابت پایین**
  (`📊 وضعیت` · `/start` · `🤖 مدل`) و **سوییچ زبان FA/EN**.
- 🔒 **امنیت**: ربات **فقط** به شناسه‌های عددی `ALLOWED_USER_IDS` پاسخ می‌دهد.

## 🧠 چطور کار می‌کند (خلاصه)

مود رایگان فری‌باف فقط وقتی سمت سرور پذیرفته می‌شود که درخواست شبیه CLI رسمی باشد. ربات این
رفتار را بازتولید می‌کند:

1. اعتبارنامهٔ فری‌باف را از `~/.config/manicode/credentials.json` می‌خواند.
2. یک **جلسهٔ** رایگان یک‌ساعته باز می‌کند/استفاده می‌کند (`/api/v1/freebuff/session`).
3. مدل را با `cost_mode: free` صدا می‌زند و پیام system را دقیقاً با
   `You are Buffy, the coding agent behind Codebuff.` شروع می‌کند (وگرنه سرور
   `free_mode_cli_required` می‌دهد).
4. برای tool-calling، تعریف ابزارها را می‌فرستد و ابزارهای درخواستی را **محلی** اجرا و نتیجه را
   به مدل برمی‌گرداند.
5. `instanceId` جلسه را نگه می‌دارد تا سشن تعاملی CLI را kick نکند (HTTP 409).

## 🚀 نصب

### نصب یک‌خطی (پیشنهادی)
```bash
git clone https://github.com/Aknuun/Freebuff-Guardian.git && cd Freebuff-Guardian && bash install.sh
```
نصب‌کننده (کامل انگلیسی) می‌پرسد:
1. **توکن ربات** از [@BotFather](https://t.me/BotFather) (`/newbot`).
2. **آیدی عددی تو** از [@userinfobot](https://t.me/userinfobot).
3. فعال‌بودن **کنترل سرور** (ابزارهای مدل).

سپس `.env` می‌سازد، `npm install` می‌زند و در صورت تمایل سرویس systemd نصب و اجرا می‌کند.

### نصب دستی
```bash
git clone https://github.com/Aknuun/Freebuff-Guardian.git
cd Freebuff-Guardian
cp .env.example .env      # سپس TELEGRAM_BOT_TOKEN و ALLOWED_USER_IDS را پر کن
npm install
node src/index.mjs
```

### سرویس systemd (دستی)
```bash
cp freebuff-guardian.service /etc/systemd/system/
# مسیرها را در صورت نیاز اصلاح کن
systemctl daemon-reload
systemctl enable --now freebuff-guardian
journalctl -u freebuff-guardian -f
```

## 💵 سهمیه و باک (محدودیت واقعی)

فری‌باف روزانه یک **بودجه** به نام **باک (Freebucks)** می‌دهد که بین همهٔ مدل‌ها مشترک است:

- هر **جلسه** معادل **قیمت ساعتی** مدل است که **یک‌بار** هنگام **شروع** کم می‌شود (نه هر پیام).
  هر جلسهٔ رایگان **۱ ساعت** است.
- بودجهٔ روزانه **نیمه‌شب Pacific** پر می‌شود و **منتقل نمی‌شود**.
- `🎟 سقف تعداد جلسه` (امروز / ۷روزه / ماهانه) یک شمارندهٔ **جدا** است؛ محدودیت اصلی همان باک است.
- بعضی مدل‌ها **پریمیوم**اند و سقف روزانهٔ کوچک جدا هم دارند.

قیمت‌ها و اینکه بودجه چقدر می‌رسد:

| مدل | باک/ساعت | جلسه با ~۷۰ باک |
|---|---|---|
| GLM 5.3 Flash · Kimi | ۵ | ~۱۴ |
| MiMo 2.5 · Solar Pro 4 | ۱۰ | ~۷ |
| DeepSeek V4 Flash | ۱۵ | ~۴ |
| Luna | ۲۰ | ~۳ |
| Gemini 3.8 | ۵۰ | ~۱ |

می‌توانی مدل‌ها را ترکیب کنی. هنگام اتمام بودجه، ربات زمان ریست را نشان می‌دهد و دکمه‌های
**➕ افزودن اکانت**، **🔄 تغییر اکانت** و **🛒 خرید اشتراک** را می‌آورد.

پلن‌های پولی (طبق گزارش خود اکانت):
Starter **۸ دلار/ماه** (ماه اول ۵) · Plus **۲۵ دلار/ماه** (اول ۱۹) · Pro **۶۰ دلار/ماه** (اول ۴۵).

## ⏳ جلسه و تایمر

- جلسهٔ رایگان دقیقاً **۱ ساعت** (سمت سرور) است و **چت آن را تمدید نمی‌کند**.
- ربات زمان باقی‌مانده را در `/status`، منوی اصلی و بلوک وضعیت نشان می‌دهد.
- قبل از انقضا هشدار می‌آید (پیش‌فرض **۵ دقیقه**، قابل تنظیم در تنظیمات → ⏰ هشدار انقضا).
- دکمهٔ **تمدید** فقط نزدیک انقضا می‌آید؛ در غیر این صورت جواب بدون دکمه است.
- پیام بعدی خودکار جلسهٔ تازه می‌سازد و اگر اکانت فعلی سهمیه نداشته باشد، ربات **خودکار
  به اکانت دیگر failover می‌کند**.

## ⌨️ کنترل سرور (ابزارهای مدل)

وقتی `ENABLE_SERVER_TOOLS=true` باشد (هنگام نصب پرسیده می‌شود)، مدل ابزار می‌گیرد و می‌تواند
روی سرور واقعاً کار کند (تا ۸ گام):

- `run_terminal_command` — اجرای هر دستور شل (با `cwd` و `timeoutSec` اختیاری).
- `read_file` — خواندن فایل متنی.
- `list_directory` — لیست یک پوشه.
- `write_file` — ساخت/بازنویسی فایل.

رفتار:
- در حین کار، **پیام بالایی** پیشرفت را نشان می‌دهد (نشانگر فکر کردن + دستورهای در حال اجرا).
  وقتی مدل تمام کرد، همان پیام به **بلوک وضعیت** (مدل · زمان مانده · سهمیه) تبدیل می‌شود و
  **جواب در پیام جداگانه** ارسال می‌شود.
- **دستورهای خطرناک** — مثل `rm -rf`، `mkfs`، `dd if=`، `shutdown`/`reboot`، `curl|sh`،
  `:(){...}`، `iptables -F` — با دکمه‌های **✅ اجرا / ❌ لغو** نشان داده می‌شوند و فقط بعد از
  تأیید تو اجرا می‌شوند. دستورهای امن خودکار اجرا می‌شوند.
- ربات با کاربر سرور (پیش‌فرض root) اجرا می‌شود. برای اجرای دستی هم از `/sh <دستور>` یا دکمهٔ
  سرور → اجرای دستور استفاده کن.

## 👤 اکانت‌ها و failover خودکار

- `/account add <name>` → **🌐 ورود وب** (ربات لینک لاگین و دکمهٔ کپی آدرس می‌دهد؛ در سایت
  فری‌باف لاگین کن).
- اکانت‌ها در `accounts/` ذخیره می‌شوند (خارج از گیت، دسترسی `600`). `default` همان حساب سرور
  است و حذف نمی‌شود.
- هر اکانت **جلسه و سهمیهٔ مستقل** خودش را دارد.
- وقتی سهمیهٔ اکانت فعال تمام شود، ربات پیام می‌دهد:
  `♻️ سهمیهٔ اکانت «X» تمام شده؛ می‌رویم روی اکانت «Y».`
  زیر آن دکمه‌های **➡️ برو به اکانت Y** و **❌ انصراف** می‌آید. اگر تا **۱ دقیقه** دکمه‌ای نزنی،
  ربات **خودکار** به اکانت بعدی سوییچ می‌کند و **جلسه قطع نمی‌شود**. این کار در خطای چت، ساخت
  جلسه و تمدید انجام می‌شود.
- **💾 بکاپ و ♻️ ریستور اکانت‌ها**: در بخش «👤 اکانت‌ها» دکمهٔ بکاپ یک فایل JSON از همهٔ
  اکانت‌ها (همراه با `default`) می‌سازد و در چت می‌فرستد. ربات **روزی یک‌بار** هم خودکار بکاپ
  می‌فرستد. برای برگرداندن، «♻️ ریستور از فایل» را بزن و همان فایل JSON را در چت بفرست.

فقط اکانت‌هایی را اضافه کن که صاحبشان رضایت دارد — افزودن اکانت اضافه می‌تواند ناقض قوانین
فری‌باف باشد و ریسک بن دارد.

## 🔒 امنیت

- فقط شناسه‌های عددی `ALLOWED_USER_IDS` پاسخ می‌گیرند؛ بقیه بی‌صدا نادیده گرفته می‌شوند.
- `.env`، `state.json`، `accounts/` و توکن‌ها **هرگز** کامیت نمی‌شوند (به `.gitignore` نگاه کن).
- ابزارهای سرور با کاربر سیستمِ ربات اجرا می‌شوند؛ لیست دسترسی سرور را بسته نگه دار.

## 🧩 عیب‌یابی / پرسش‌های رایج

- **`free_mode_cli_required`** — درخواست باید پیشوند رسمی پیام system را داشته باشد؛ ربات
  خودکار اضافه می‌کند. اگر باز دیدی، نسخه را به‌روز کن.
- **`session_superseded` (409)** — دو نمونه با یک اکانت کار کرده‌اند. ربات همیشه `instanceId`
  جلسهٔ فعال را استفاده می‌کند؛ روی یک اکانت کلاینت دوم اجرا نکن.
- **`waiting_room_required` (428)** — جلسه وسط درخواست تمام شده؛ پیام بعدی خودکار جلسهٔ تازه
  می‌سازد.
- **اتمام سهمیه** — باک یک بودجهٔ روزانه است؛ ربات زمان ریست را نشان می‌دهد. صبر کن، ارتقا بده
  یا اکانت عوض کن.
- **مدل می‌گوید شل ندارم** — مطمئن شو `ENABLE_SERVER_TOOLS=true` است و اکانت فعال سهمیه دارد.

```
├── backup.mjs     بکاپ/ریستور اکانت‌ها به‌صورت فایل JSON
├── chat.mjs       جلسه + agent-runs + chat/completions (+ پشتیبانی ابزار)
└── bot.mjs        رابط تلگرام، دکمه‌ها، ابزارهای مدل و failover
```
