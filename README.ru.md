## О Freebuff

**Freebuff** — это *100% бесплатный* ИИ‑агент для программирования, который финансируется
рекламой, а не подпиской. Он доступен в нескольких формах — **CLI**, **Desktop**, **Web**,
**Cloud** и **Chat** — и позволяет бесплатно использовать мощные модели. Работает прямо на
вашей машине/сервере с реальными файлами и командами.

- 🌐 Сайт: **https://freebuff.com**
- 💻 Установка CLI: `npm i -g freebuff`, затем `freebuff`
- 🧩 Бесплатно для всех: без API‑ключа и без банковской карты
- 📉 Ограничено дневным бюджетом **баков (Freebucks)** — см. ниже

`Freebuff Guardian` — независимый Telegram‑интерфейс для Freebuff и **не связан** с командой
Freebuff. Для работы всё равно нужен аккаунт Freebuff и CLI на том же сервере.

## Что такое Freebuff Guardian?

Telegram‑бот, который позволяет **полностью управлять Freebuff и общаться с ним на сервере —
без SSH**. Вы устанавливаете его один раз, а дальше всё происходит в Telegram: чат с моделью,
переключение моделей, управление сервером, несколько аккаунтов Freebuff, просмотр лимита и
выполнение команд на машине самим моделью.

Он создан для тех, кто держит Freebuff на удалённом VPS и хочет удобно управлять им (и сервером)
с телефона из любого места.

## ✨ Возможности

- 💬 **Чат с бесплатными моделями** из Telegram, несколько независимых сессий с отдельной историей.
- 🤖 **Управление моделями**: настоящее переключение — бот закрывает текущую сессию и заново
  делает admission с нужной моделью (сервер привязывает бесплатную сессию к одной модели).
  Для каждой модели показывается **цена (баков/час)** и **остаток часов сегодня**; недоступные
  модели показаны **серыми и не нажимаются**.
- 🎛 **Режим ответа**: 🧩 По умолчанию · ⚡ Быстрый (Lite) · 🛠 Сборка (MAX/Build) · 🗺 План (Plan).
- ⚙️ **Настройки**: режим ответа, реклама, активная модель, порог предупреждения об истечении и
  **автопродление сессии** (предупреждает за 5 минут и продлевает сессию автоматически; есть кнопка отмены).
- 👤 **Несколько аккаунтов Freebuff** (совместное использование): добавление через официальный
  **вход в веб** (сервер для этого аккаунта не нужен, с кнопкой копирования ссылки). При
  исчерпании лимита бот спрашивает кнопками и, если ответа нет в течение **1 минуты**,
  **автоматически переключается (failover)** на следующий аккаунт, не обрывая сессию.
- 💾 **Бэкап/восстановление аккаунтов**: ежедневный автоматический бэкап и кнопки бэкапа и
  восстановления из файла в меню аккаунтов.
- ⏳ **Таймер сессии**: бесплатная сессия живёт ровно **1 час** (на стороне сервера); бот
  показывает обратный отсчёт (например, «осталось 51 мин»), предупреждает до истечения и показывает кнопку **Продлить**
  только рядом с истечением.
- 💵 **Просмотр лимита**: использовано/осталось **баков** и отдельный счётчик сессий — и в
  «Статусе», и в «Аккаунтах». При исчерпании — понятное сообщение и кнопки
  **Добавить аккаунт / Сменить аккаунт / Купить план**.
- ⌨️ **Управление сервером (инструменты модели)**: модель может выполнять
  `run_terminal_command`, `read_file`, `list_directory` и `write_file` на этом сервере в
  многошаговом цикле. Опасные команды требуют подтверждения **Запустить / Отмена**.
- 🎛 **Два интерфейса сразу**: inline‑кнопки для всего + **фиксированная нижняя клавиатура**
  (`📊 Статус` · `/start` · `🤖 Модель`) и **переключатель языка FA/EN**.
- 🔒 **Безопасность**: бот отвечает **только** на числовые id из `ALLOWED_USER_IDS`.

## 🧠 Как это работает (кратко)

Бесплатный режим Freebuff принимается сервером только если запрос похож на официальный CLI.
Бот воспроизводит это поведение:

1. Читает учётные данные Freebuff из `~/.config/manicode/credentials.json`.
2. Открывает/использует бесплатную **сессию** на один час (`/api/v1/freebuff/session`).
3. Вызывает модель с `cost_mode: free` и системным промптом, который начинается ровно с
   `You are Buffy, the coding agent behind Codebuff.` (иначе сервер вернёт
   `free_mode_cli_required`).
4. Для tool‑calling отправляет определения инструментов и выполняет запрошенные инструменты
   **локально**, возвращая результаты модели.
5. Сохраняет `instanceId` сессии, чтобы не выбивать интерактивную CLI‑сессию (HTTP 409).

## 🚀 Установка

### Установка одной строкой (рекомендуется)
```bash
git clone https://github.com/Aknuun/Freebuff-Guardian.git && cd Freebuff-Guardian && bash install.sh
```
Установщик (полностью на английском) спросит:
1. **Токен бота** у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. **Ваш числовой id** у [@userinfobot](https://t.me/userinfobot).
3. Включить ли **управление сервером** (инструменты модели).

Затем создаст `.env`, выполнит `npm install` и (по желанию) установит и запустит сервис systemd.

### Ручная установка
```bash
git clone https://github.com/Aknuun/Freebuff-Guardian.git
cd Freebuff-Guardian
cp .env.example .env      # заполните TELEGRAM_BOT_TOKEN и ALLOWED_USER_IDS
npm install
node src/index.mjs
```

### Сервис systemd (вручную)
```bash
cp freebuff-guardian.service /etc/systemd/system/
# при необходимости поправьте пути
systemctl daemon-reload
systemctl enable --now freebuff-guardian
journalctl -u freebuff-guardian -f
```

## 💵 Лимит и баки (реальное ограничение)

Freebuff выдаёт **дневной бюджет** под названием **баки (Freebucks)**, общий для всех моделей:

- Каждая **сессия** стоит **часовую цену** модели в баках, списывается **один раз** при
  **старте** (не за каждое сообщение). Каждая бесплатная сессия длится **1 час**.
- Дневной бюджет **обновляется в полночь по Pacific** и **не переносится**.
- `🎟 счётчик сессий` (день 5 / 7 дней 14 / месяц 40) — **отдельный**. Так как сессия длится
  всего **1 час**, для дешёвых моделей (GLM) этот лимит заканчивается **раньше** баков.
- Некоторые модели **премиальные** и имеют свой небольшой дневной лимит.

Цены и на сколько хватает бюджета:

| Модель | баков/час | сессий на ~70 баков | реально часов/день (лимит сессий) |
|---|---|---|---|
| GLM 5.3 Flash · Kimi | 5 | ~14 | **5 ч** |
| MiMo 2.5 · Solar Pro 4 | 10 | ~7 | 5 ч |
| DeepSeek V4 Flash | 15 | ~4 | 4 ч |
| Luna | 20 | ~3 | 3 ч |
| Gemini 3.8 | 50 | ~1 | 1 ч |

**Сколько аккаунтов для полного бесплатного покрытия?** (GLM; лимиты на аккаунт: день 5 · неделя 14 · месяц 40 ч):
полные сутки ≈ **5 аккаунтов** · полная неделя ≈ **12 аккаунтов** · месяц 24/7 ≈ **18 аккаунтов**.

### 🌐 Проблема IP (`ip_capped`)

Лимит `ip_capped` считается по **IP сервера** и общий для всех аккаунтов. Решение — дать каждому
аккаунту свой **прокси**, чтобы запросы шли с другого IP:

- В боте: «👤 Аккаунты → 🌐 Account proxy (защита от бана по IP)» или
  `/proxy http://user:pass@host:port` (удалить — `/proxy off`). Прокси хранится в файле аккаунта и
  попадает в бэкап.
- Для аккаунта `default` задайте переменную `FREEBUFF_PROXY` в `.env`.
- **Работают только HTTP/HTTPS‑прокси** (например, `http://1.2.3.4:8080` или `http://user:pass@1.2.3.4:8080`).
- После настройки кнопка **«🧪 Test proxy»** покажет прямой и проксированный IP, чтобы убедиться, что IP изменился.
- ❌ Ссылки `t.me/proxy?...` (MTProto) — только для Telegram и НЕ подойдут.
- ❌ Чистый SOCKS не подойдёт; если у клиента только SOCKS, включите ещё **HTTP** inbound
  (xray/v2ray/sing-box) и укажите, например, `http://127.0.0.1:8080`. Каждому аккаунту — свой прокси.

Модели можно комбинировать. При исчерпании бот показывает время сброса и кнопки
**➕ Добавить аккаунт**, **🔄 Сменить аккаунт** и **🛒 Купить план**.

Платные планы (по данным аккаунта):
Starter **$8/мес** (первый $5) · Plus **$25/мес** (первый $19) · Pro **$60/мес** (первый $45).

## ⏳ Сессия и таймер

- Бесплатная сессия живёт ровно **1 час** (на сервере), и **чат её не продлевает**.
- Бот показывает остаток в `/status`, главном меню и блоке статуса.
- Предупреждение за **5 минут** (настраивается: Настройки → ⏰).
- Кнопка **Продлить** появляется только перед истечением; иначе ответ без кнопок.
- Следующее сообщение само начнёт новую сессию, а если у аккаунта нет лимита — бот
  **автоматически переключится** на другой аккаунт.

## ⌨️ Управление сервером (инструменты модели)

При `ENABLE_SERVER_TOOLS=true` (спрашивается при установке) модель получает инструменты и может
реально работать на сервере (до 8 шагов):

- `run_terminal_command` — выполнить любую команду (опционально `cwd`, `timeoutSec`).
- `read_file` — прочитать текстовый файл.
- `list_directory` — список каталога.
- `write_file` — создать/перезаписать файл.

Поведение:
- Во время работы **верхнее сообщение** показывает прогресс (индикатор размышления и
  выполняемые команды). Когда модель закончит, оно становится **блоком статуса**
  (модель · остаток времени · лимит), а **ответ приходит отдельным сообщением**.
- **Опасные команды** — например `rm -rf`, `mkfs`, `dd if=`, `shutdown`/`reboot`, `curl|sh`,
  `:(){...}`, `iptables -F` — показываются с кнопками **✅ Запустить / ❌ Отмена** и выполняются
  только после подтверждения. Безопасные команды выполняются автоматически.
- Бот работает от пользователя сервера (по умолчанию root). Для ручного запуска используйте
  `/sh <команда>` или Сервер → Запуск команды.

## 👤 Аккаунты и авто‑failover

- `/account add <name>` → **🌐 Вход в веб** (бот даёт ссылку и кнопку копирования; войдите на
  сайте Freebuff).
- Аккаунты хранятся в `accounts/` (вне git, режим `600`). `default` — аккаунт сервера, его
  нельзя удалить.
- У каждого аккаунта **своя сессия и свои баки**.
- На странице «Аккаунты» показываются данные только **активного** аккаунта; нажмите кнопку любого
  аккаунта — он активируется, и информация появится там же. Кнопки **▶️ Start session**,
  **➕ Add account** и **🗑 Delete account** на той же странице.
- Когда лимит активного аккаунта исчерпан, бот пишет:
  `♻️ Account "X" quota is used up; switching to "Y".`
  и показывает кнопки **➡️ Switch to Y** и **❌ Cancel**. Если ничего не нажать в течение
  **1 минуты**, бот **сам** переключается на следующий аккаунт, и **сессия не обрывается**.
  Это срабатывает при ошибке чата, старте и продлении сессии.
- **💾 Бэкап и ♻️ восстановление аккаунтов**: в меню «Аккаунты» кнопка бэкапа создаёт JSON‑файл
  со всеми аккаунтами (включая `default`) и отправляет его в чат. Бот также отправляет бэкап
  **раз в день** автоматически. Для восстановления нажмите «♻️ Restore from file» и отправьте
  этот JSON‑файл в чат.

Добавляйте только аккаунты с согласия их владельцев — дополнительные аккаунты могут нарушать
правила Freebuff и грозят баном.

## 🔒 Безопасность

- Отвечает только числовым id из `ALLOWED_USER_IDS`; остальные игнорируются молча.
- `.env`, `state.json`, `accounts/` и секреты **никогда** не коммитятся (см. `.gitignore`).
- Инструменты сервера выполняются от пользователя бота. Держите список доступа узким.

## 🧩 Решение проблем / FAQ

- **`free_mode_cli_required`** — запрос должен содержать официальный префикс системного промпта;
  бот добавляет его сам. Если всё ещё видите — обновите версию.
- **`session_superseded` (409)** — два клиента с одним аккаунтом. Бот всегда использует
  `instanceId` активной сессии; не запускайте второй клиент на том же аккаунте.
- **`waiting_room_required` (428)** — сессия истекла посреди запроса; следующее сообщение
  создаст новую.
- **Лимит исчерпан** — баки дневные; бот показывает время сброса. Подождите, обновите план или
  смените аккаунт.
- **Модель говорит, что нет shell** — проверьте `ENABLE_SERVER_TOOLS=true` и наличие аккаунта
  с лимитом.

```
src/
├── index.mjs      точка входа (конфиг и запуск бота)

├── chat.mjs       сессия + agent-runs + chat/completions (+ инструменты)
└── bot.mjs        Telegram UI, кнопки, инструменты модели, failover
```
